# Agent Instructions

When submitting work for this repository, please adhere to the following special instructions:

1.  **Include the compiled JAR file in the commit.** After all code changes are complete, run `mvn clean package` to build the plugin.
2.  **Include the `target` directory** in the commit, as this contains the compiled JAR file.
3.  Ensure that the `.gitignore` file (if one is created in the future) does not exclude the `target/` directory or `*.jar` files.
